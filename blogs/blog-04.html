Graph Neural Networks: A Practical Introduction

Most real-world data isn't a grid or a sequence — it's a graph. Social networks, molecular structures, citation networks, knowledge bases — all of these are naturally represented as nodes and edges. Graph Neural Networks (GNNs) are the tool that lets neural networks reason over this kind of data.

The message-passing framework

Almost all GNN architectures can be understood through the lens of message passing. In each layer, every node aggregates information from its neighbours, then updates its own representation based on that aggregated message. 

# Conceptually, one GNN layer for node v:
h_v_new = UPDATE(h_v, AGGREGATE({h_u : u in N(v)}))

The choice of AGGREGATE (mean, sum, max, attention) and UPDATE (MLP, GRU) distinguishes different architectures like GCN, GraphSAGE, and GAT.

Graph Convolutional Networks (GCN)

GCN (Kipf & Welling, 2017) uses a normalised mean aggregation with a learned weight matrix: 

H^(l+1) = sigma( D^(-1/2) A_hat D^(-1/2) H^(l) W^(l) )

# A_hat = A + I  (adjacency + self-loops)
# D     = degree matrix

This is fast and works well on homophilic graphs (where connected nodes tend to share labels), but it treats all neighbours equally — a limitation addressed by GAT.

Getting started with PyTorch Geometric

import torch
from torch_geometric.nn import GCNConv
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root='/tmp/Cora', name='Cora')

class GCN(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = GCNConv(dataset.num_features, 64)
        self.conv2 = GCNConv(64, dataset.num_classes)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = self.conv1(x, edge_index).relu()
        x = torch.dropout(x, p=0.5, train=self.training)
        return self.conv2(x, edge_index)

PyTorch Geometric makes it easy to get started. The Cora citation dataset is the classic benchmark — ~2700 nodes, 7 classes, and a transductive semi-supervised node classification task.

When to use GNNs

  • Node classification — predict a label for each node (e.g., paper category).
  • Link prediction — predict whether an edge should exist (e.g., recommendation).
  • Graph classification — predict a label for the whole graph (e.g., molecule property).

If your data has a natural relational structure, try a GNN before reaching for a flat feature vector approach.
