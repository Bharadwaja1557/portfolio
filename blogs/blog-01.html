Understanding Attention Mechanisms in Transformers

Attention is the core innovation that made Transformers possible. In this post I walk through scaled dot-product attention from scratch, explain why positional encoding matters, and build intuition for what "multi-head" actually means.

The core idea

Each token produces three vectors — a Query (Q), a Key (K), and a Value (V) — through learned linear projections. The output for each token is a weighted sum of all value vectors, where the weights come from how well that token's query matches each key.

Scaled dot-product attention

Attention(Q, K, V) = softmax( QK^T / sqrt(d_k) ) · V

We scale by sqrt(d_k) to prevent large dot products from pushing softmax into regions with tiny gradients. The softmax turns scores into a probability distribution; we take the weighted sum of values.

Why multi-head?

A single head learns one way to relate tokens. Multi-head attention runs several operations in parallel on projected subspaces, then concatenates results — letting the model simultaneously attend to syntactic, semantic, and positional relationships.

MultiHead(Q,K,V) = Concat(head_1,...,head_h) W^O
where  head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)

Position matters

Attention is permutation-invariant — it does not inherently know token order. Positional encodings inject sequence position by adding a position-specific vector to each token embedding before the attention layers.

Without positional encodings, a Transformer produces the same output for "dog bites man" and "man bites dog".

Takeaways

  • Attention lets every token directly interact with every other in O(n²) time.
  • Scaling prevents vanishing gradients in high-dimensional spaces.
  • Multiple heads capture different relationship types in parallel.
  • Position encodings are essential for order awareness.
