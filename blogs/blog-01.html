Understanding Attention Mechanisms in Transformers

Attention is the core innovation that made Transformers possible — and understanding it deeply is key to working with any modern language or vision model. In this post, I'll walk through the mechanics of scaled dot-product attention from scratch, explain why positional encoding matters, and build intuition for what "multi-head" actually means.

The core idea

At its heart, attention answers a simple question: given a query, which parts of the input are most relevant? Each token produces three vectors — a Query (Q), a Key (K), and a Value (V) — through learned linear projections. The output for each token is a weighted sum of all the value vectors, where the weights come from how well that token's query matches each key.

Scaled dot-product attention

The formula is deceptively simple:

Attention(Q, K, V) = softmax( QK^T / sqrt(d_k) ) · V

The dot product QK^T measures similarity between all query-key pairs simultaneously. We scale by sqrt(d_k) to prevent the dot products from growing large in high dimensions, which would push the softmax into regions with very small gradients. The softmax then turns these scores into a probability distribution, and we take the weighted sum of the values.

Why multi-head?

A single attention head learns one way to relate tokens. Multi-head attention runs several attention operations in parallel on projected subspaces of the input, then concatenates the results. This lets the model simultaneously attend to different types of relationships — syntactic, semantic, positional — within the same layer. 

MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W^O

where head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)

Position matters

Attention itself is permutation-invariant — it doesn't inherently know the order of tokens. Positional encodings (either sinusoidal or learned) inject sequence position information by adding a position-specific vector to each token embedding before feeding it to the attention layers.

Without positional encodings, a Transformer would produce the same output regardless of whether you fed it "dog bites man" or "man bites dog".

Takeaways

  • Attention lets every token directly interact with every other token in O(n²) time.
  • Scaling prevents vanishing gradients in high-dimensional spaces.
  • Multiple heads capture different relationship types in parallel.
  • Position encodings are essential for order awareness.
