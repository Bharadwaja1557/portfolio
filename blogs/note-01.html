Softmax temperature controls sharpness, not magnitude

The temperature parameter τ in softmax(x / τ) is one of those things that looks trivial until you actually need to tune it. Quick note on what it does and where it matters.

What temperature does

Softmax always outputs a probability distribution summing to 1. Temperature does not change that — it changes how peaked or flat the distribution is:

  • τ < 1 — sharpens the distribution (model becomes more confident, greedy)
  • τ = 1 — standard softmax, no change
  • τ > 1 — flattens the distribution (model becomes less confident, more random)
import numpy as np

def softmax_temp(x, tau):
    e = np.exp((x - x.max()) / tau)
    return e / e.sum()

logits = np.array([2.0, 1.0, 0.1])

print(softmax_temp(logits, tau=0.5))  # sharper: [0.844, 0.143, 0.013]
print(softmax_temp(logits, tau=1.0))  # normal:  [0.659, 0.242, 0.099]
print(softmax_temp(logits, tau=2.0))  # flatter: [0.507, 0.333, 0.160]

Where this matters

LLM sampling: when you set temperature in a chat model, you are literally dividing the logits before softmax. Low temperature → the model almost always picks its top token. High temperature → more surprising outputs.

Knowledge distillation: the teacher's soft labels carry more information at higher temperatures because the small probabilities on non-target classes become more visible. This is the key insight from Hinton et al.'s original distillation paper.

Temperature is a knob on how decisive the model is, not on how smart it is.
